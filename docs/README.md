## Directory contract

| Directory | Purpose | Authority |
| --- | --- | --- |
| `product/`, `architecture/`, `engineering/`, `release/` | Current behavior and operating contracts | Must agree with runtime, tests, verifiers, and manifest |
| `adr/` | Durable accepted architecture decisions | Decision authority; later ADRs may supersede earlier ones |
| `strategy/` | Proposed direction and research | Non-authoritative until implemented and reflected in current contracts |
| `history/`, `migration/`, `performance/` | Dated execution, retirement, and measurement evidence | Historical context only |
| `assets/product/` | Synthetic screenshots generated by `npm run capture:ui` | Visual evidence, never runtime proof by itself |
