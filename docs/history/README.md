# Historical evidence

This directory contains dated delivery evidence, not current product instructions. Runtime behavior, tests, executable verifiers, current guides, and [`PRODUCT_MANIFEST.yaml`](../../PRODUCT_MANIFEST.yaml) always take precedence.

## Collections

- [Implementation plans](plans/README.md) preserve accepted plans and their completion notes.
- [Legacy migration records](../migration/bubu-bi-retirement-inventory.md) preserve the Wails retirement decision and final disposition.
- [Performance snapshots](../performance/reference-desktop-2026-07-17.md) preserve measurements tied to a specific date, revision, and device.

Historical branch names, test counts, tool versions, and incomplete statuses are retained only as evidence of what was known at that time. They must not be used to infer the current branch topology or capability state.
